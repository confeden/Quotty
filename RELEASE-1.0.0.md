# Quotty 1.0.0

Первый релиз. Тонкая полоска поверх окон показывает остаток квоты того ИИ-инструмента, в котором вы сейчас работаете, и время до сброса лимита.

## Что умеет

- **Три семейства сразу:** Claude (приложение и Claude Code/CLI), Codex (приложение и CLI), Antigravity (2.0, IDE и CLI).
- **Сама переключается** на тот инструмент, окно которого было активно последним — включая CLI, запущенный в терминале. Можно и закрепить конкретный источник.
- **Строка на каждое окно лимита:** 5 часов, неделя, месяц — что отдаёт сервис. Точное время сброса и остаток.
- **Полоса расхода с отметкой времени:** зелёная — идёте с запасом (из края расхода поднимаются пузырьки), жёлтая — тратите быстрее, чем идёт окно, оранжевая — лимит выбран.
- **Настройки в одном окне:** непрозрачность (слайдер и готовые значения), анимация, режим заголовка (среда и тариф / только семейство / скрыть), список источников с их состоянием, интервал опроса, автозапуск, ярлык на рабочем столе.
- **Не мешает:** нет кнопки на панели задач, всегда поверх окон, перетаскивается мышью, позиция запоминается.
- **Проверка обновлений** раз в 8 часов по тегу релиза на GitHub — только уведомление и ссылка, ничего не скачивается само.

## Приватность

Нет телеметрии. Нет рекламы. Нет серверов автора: запросы идут только к API самих сервисов и к локальному языковому серверу Antigravity на 127.0.0.1. Токены читаются локально, из хранилищ уже установленных программ, и уходят только тому сервису, которому принадлежат.

## Установка

Скачайте `Quotty-Setup-1.0.0.exe` и запустите — установка в профиль пользователя, права администратора не нужны. Автозапуск можно включить сразу в установщике или позже в настройках.

Windows 10/11 x64.

## Как пользоваться

- ЛКМ по полоске — перетащить, ПКМ — настройки.
- Меню в трее: автозапуск, настройки, обновить сейчас, выход.
