# Quotty

Интерактивный счётчик лимитов нейросетей в минималистичном стиле.

Тонкая полоска поверх всех окон: показывает, сколько квоты осталось у ИИ-инструмента, в котором вы сейчас работаете, и когда лимит обнулится.

Полоска сама переключается на тот инструмент, окно которого было активно последним.
Поддерживаются три семейства:

- **Claude** — приложение Claude Desktop и Claude Code / CLI;
- **Codex** — приложение Codex/ChatGPT и Codex CLI;
- **Antigravity** — Antigravity 2.0, Antigravity IDE и CLI.

## Возможности

- Отдельная строка на каждое окно лимита (от 5 часов до месяца — что отдаёт сервис).
- Полоса расхода с белой отметкой времени: видно, тратите вы быстрее или медленнее, чем истекает лимит.
  - зелёная — идёте с запасом, из края расхода поднимаются пузырьки;
  - жёлтая — тратите быстрее, чем идёт время;
  - оранжевая — лимит выбран полностью.
- Точное время сброса и сколько до него осталось.
- Автопереключение по активному окну — включая CLI, запущенный в терминале.
- Настройка непрозрачности (слайдер и готовые значения), режим заголовка: среда и тариф / только семейство / скрыть.
- Работает без кнопки на панели задач: перетаскивание — ЛКМ, настройки — ПКМ по полоске или через трей.
- Проверка обновлений раз в 8 часов по тегу релиза на GitHub.

## Приватность

- **Нет телеметрии.** Ни аналитики, ни счётчиков, ни сбора статистики.
- **Нет рекламы.** Никаких баннеров, партнёрских ссылок и «предложений».
- **Нет серверов автора.** Программа обращается только к API самих сервисов (Anthropic, OpenAI) и к локальному языковому серверу Antigravity на 127.0.0.1.
- Токены читаются локально, из хранилищ уже установленных программ, и уходят только тому сервису, которому принадлежат. Quotty ничего не пишет в чужие файлы и не обновляет чужие токены.
- Единственный сетевой запрос — проверка новой версии на GitHub (только чтение тега последнего релиза, раз в 8 часов).
- Свои настройки Quotty хранит в `%APPDATA%\Quotty\settings.json`.

## Откуда берутся данные

| Инструмент | Источник |
|---|---|
| Claude | локальный токен Claude Desktop → официальный эндпоинт использования аккаунта |
| Codex | `~/.codex/auth.json` (общий у приложения и CLI) → эндпоинт использования Codex |
| Antigravity | локальный языковой сервер Antigravity — тот же запрос, что делает панель расхода в самой IDE |

Если инструмент не установлен или не запущен, его источник просто помечается как недоступный — остальные продолжают работать.

## Установка

Скачайте `Quotty-Setup.exe` со страницы [релизов](https://github.com/confeden/Quotty/releases) и запустите. Установка идёт в профиль пользователя, права администратора не нужны.

При установке можно сразу включить автозапуск; позже это переключается в настройках или в меню трея.

## Как пользоваться

- **ЛКМ по полоске** — перетащить в удобное место (позиция запоминается).
- **ПКМ по полоске** — открыть настройки (открываются по центру того монитора, где вы находитесь).
- **Меню в трее** — можно настроить и там.


## Требования

- Windows 10/11, x64.
- Установленный инструмент, чью квоту нужно смотреть: Claude Desktop, Codex CLI/приложение, Antigravity.
- Для Antigravity — запущенное приложение или IDE (квота живёт в его языковом сервере).

## Сборка из исходников

```
cargo build --release
```

Инсталлятор (нужен [Inno Setup 6](https://jrsoftware.org/isdl.php)):

```
powershell -ExecutionPolicy Bypass -File tools\build-installer.ps1
```
